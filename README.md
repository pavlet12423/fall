# fall

Пайплайн плотного оптического потока (dense optical flow) по последовательности кадров.

## Что уже есть

- `data/frames/` — кадры (`frame_001.png` … `frame_040.png`, 1280×720 RGBA PNG, без пережатия).
- `fallflow/` — пакет: поиск/загрузка кадров, расчёт потока, статистика, визуализация, CLI.
- `outputs/` — результаты (`.npy` поля, HSV-картинки, отчёт). **В Git не коммитится.**

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
# все пары подряд, Farnebäck, с наложением стрелок и контактным листом
.venv/bin/python -m fallflow --frames data/frames --out outputs --arrow-step 32 --montage

# быстро и грубо: DIS на половинном разрешении
.venv/bin/python -m fallflow --method dis --scale 0.5

# зашумлённые кадры: сглаживание 5x5 перед сопоставлением
.venv/bin/python -m fallflow --blur 5

# сравнить каждый кадр с пятым следующим (для крупных смещений)
.venv/bin/python -m fallflow --stride 5

# посмотреть, что будет считаться, ничего не считая
.venv/bin/python -m fallflow --dry-run
```

Полный список флагов: `.venv/bin/python -m fallflow --help`.

## Как добавлять новые кадры

Кидаете файлы в `data/frames/` (порядок — «человеческий»: `frame_2` раньше `frame_10`) и
повторяете запуск. Уже посчитанные пары пропускаются, считаются только новые —
догружать можно сколько угодно, хоть по одному кадру.

## Результаты

| Файл | Смысл |
| --- | --- |
| `outputs/flow/flow_0006_0007.npy` | поле потока `float32[H, W, 2]`, канал 0 — dx, канал 1 — dy, в пикселях исходного кадра |
| `outputs/viz/flow_0006_0007.png` | HSV: оттенок = направление, яркость = величина |
| `outputs/viz/flow_0006_0007_arrows.png` | стрелки поверх кадра |
| `outputs/stats/flow_0006_0007.json` | статистика конкретной пары (переживает перезапуски) |
| `outputs/report.csv`, `report.json` | статистика по **всей** последовательности |
| `outputs/montage.png` | контактный лист всех пар |

Статистика по паре: средняя/медианная/p95/максимальная величина, доля «движущихся»
пикселей, среднее направление в градусах и его когерентность (1 = всё движение в одну сторону).

```python
from fallflow import load_flow, flow_stats
flow = load_flow("outputs/flow/flow_0006_0007.npy")
print(flow_stats(flow))
```

## Наблюдения по первым 40 кадрам

- `frame_001.png` и `frame_002.png` **полностью одинаковы** (совпадает md5) — между ними потока нет;
  если это артефакт экспорта, кадр стоит убрать.
- Средняя величина потока: максимум 8.56 px (пара 6→7), медиана 5.19 px, минимум 0 (1→2).
  Виден спад с ~7.5 px на старте до плато ~4.2–4.8 px после 20-го кадра.
- Доля движущихся пикселей держится около 52 % — много мелкого «фонового» потока,
  типично для зашумлённой картинки. Проверять `--blur 5`.
- Спайки 6.0–6.6 px повторяются примерно каждые 5–7 пар (21→22, 26→27, 29→30, 31→32, 36→37).
- Когерентность направления медиана 0.67: движение в кадре преимущественно однонаправленное,
  средний угол около −4° (почти горизонтальное).
